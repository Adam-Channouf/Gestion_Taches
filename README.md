# Application Python de Gestion des Tâches

## 1. Présentation du projet

Ce projet consiste à réaliser une application Python simple permettant de gérer les tâches quotidiennes à partir d'une interface en console.

## 2. Fonctionnalités

L'application propose les fonctionnalités suivantes :

- **Ajouter une tâche :** saisir un titre et l'ajouter à la liste. Les titres vides sont refusés.
- **Afficher les tâches :** afficher toutes les tâches enregistrées avec leur numéro.
- **Rechercher une tâche :** rechercher les tâches à partir d'un mot-clé contenu dans leur titre.
- **Quitter :** fermer le programme.

## 3. Étapes réalisées

1. Création du fichier `main.py`.
2. Développement du menu principal.
3. Implémentation de l'ajout des tâches.
4. Implémentation de l'affichage des tâches.
5. Implémentation de la recherche par mot-clé.
6. Gestion des erreurs et des choix invalides.
7. Test des fonctionnalités de l'application.

## 4. Technologies utilisées

- Python
- Visual Studio Code
- Git
- GitHub

## 5. Exécution du programme

Pour exécuter l'application :

1. Ouvrir le dossier du projet dans Visual Studio Code.
2. Ouvrir le fichier `main.py`.
3. Cliquer sur le bouton **Run Python File** en haut à droite.
4. Utiliser le menu affiché dans le terminal pour gérer les tâches.
